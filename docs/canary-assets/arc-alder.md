# Arc & Alder canary assets

These original assets support the fictional Arc & Alder Cycle Atelier pipeline canary. They are not evidence about a real business.

## Asset set

- `hero-workshop.webp`: wide atelier interior with left-side copy space
- `bike-fit.webp`: portrait fitting and measurement scene
- `wheel-building.webp`: workshop detail for gallery or service storytelling
- `logo.svg`: repository-native vector mark and wordmark

## Generation provenance

The three photographs were generated with OpenAI's built-in image generation tool on September 17, 2026. Prompts required a believable independent bicycle workshop, forest-green millwork, warm birch surfaces, mechanically plausible bicycles and tools, no identifiable people, no text, no logos, and no unsupported credentials. The final outputs were visually inspected before inclusion and encoded as WebP at quality 84.

The logo was authored as SVG in the repository so it remains sharp, lightweight, and editable.
