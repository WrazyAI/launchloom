# A1-informed design directions

These concepts use structural ideas observed through the A1 Gallery MCP. They
do not reproduce source branding, copy, assets, or trade dress. Run
`npm run build:a1-showcase` to generate the five scrollable prototypes.

## Quiet Practice

Reference evidence: One Manor Place and TR Studio.

Use an asymmetric editorial opening, expressive serif typography, a service
index instead of cards, portrait-led trust, and a low-pressure consultation
path. This direction suits care, wellness, therapy, architecture, and other
consultation-led businesses.

## Rapid Response

Reference evidence: Foster & Reeves and Desourdy.

Use a full-bleed problem statement, utility navigation, a service ledger,
visible coverage information, and separate phone and request-service paths.
This direction suits urgent and planned local trades.

## Neighborhood Table

Reference evidence: Eislab, Touchy Coffee, and Impossible Foods.

Use a loose visual collage, a menu or shelf presentation, visible hours and
directions, and a visit-first conversion path. This direction suits food,
hospitality, specialty retail, florists, and community venues.

## Kinetic Club

Reference evidence: Lando Norris, David Alaba, and Google Cloud x Team USA.

Use a full-viewport action opening, oversized condensed typography, horizontal
program bands, and a goal-first trial path. This direction suits fitness,
sports, automotive, and performance businesses.

## Clear Counsel

Reference evidence: Noah Stokes, Advis Law, and Meaning Ltd.

Use a narrow positioning statement, restrained typography, a ruled expertise
ledger, named-professional proof, and a calm confidential inquiry. This
direction suits legal, financial, consulting, insurance, and engineering
businesses.

## Similarity rules

Do not treat variation as a palette swap. A design family must materially vary
its hero composition, navigation, typography, section order, service
presentation, proof pattern, imagery grammar, and conversion path. Avoid a
universal three-card grid, a fixed homepage sequence, decorative numbering,
and the same floating call to action across every industry.

## Pipeline mapping

The production renderer exposes five bounded families: `image-mosaic`,
`cinematic-premium`, `atmospheric-editorial`, `project-showcase`, and
`studio-minimal`. Intake language may request one explicitly. Otherwise the
stable variant selector distributes suitable families within the selected
care, trades, or general recipe. Run `npm run build:design-families` to render
all five through the real client-site template.
