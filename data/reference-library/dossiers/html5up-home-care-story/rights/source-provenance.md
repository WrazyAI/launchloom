## What is retained and changed

The layout and interaction vocabulary is adapted from Story: a split first chapter, alternating image-and-copy spotlights, a horizontal image rail, and editorial full-width chapters. A local study was rendered from the pinned template after its CSS base and structure were modified; text, navigation, service rows, colors, photos, metadata, FAQ, form, and interaction were rewritten for this fictional home-support concept. The original source package and runtime code are not retained in this dossier. Original demo photography, Font Awesome files, Google Fonts import, and upstream JavaScript/vendor libraries were not copied. Displayed photos were generated for this study and are listed with prompts and hashes in `generated-assets.md`.

The desktop/mobile captures are of this clearly modified local adaptation, not screenshots of the HTML5 UP live demo. The screenshot adaptations are stored under the same CC BY 3.0 attribution context as the modified template. This study is not endorsed by HTML5 UP or AJ and must not be used to imply such endorsement.

Visible attribution appeared in the local study footer. Source CSS is not retained here; the exact source revision, license, README hashes, and capture history remain in this provenance record. Downstream adaptations must preserve any attribution required by the license when distributing a derivative; LaunchLoom transfers design mechanics only and does not copy this source code or its brand assets.
