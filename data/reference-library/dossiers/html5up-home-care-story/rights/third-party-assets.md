# Included asset and dependency audit

- Retained upstream implementation assets: `render/assets/css/main.css` and `render/assets/css/noscript.css`, based on the pinned Story source and covered by the retained CC BY 3.0 license record.
- The original upstream CSS header attribution is preserved. Google Fonts and Font Awesome imports were removed. Demo photos, font binaries, jQuery/plugins, and upstream script bundles were not copied.
- `render/assets/css/adaptation.css` and `render/assets/js/prototype.js` were written for this fictional study and use native CSS, IntersectionObserver, and standard browser form events.
- All rendered photographs are generated originals described in `generated-assets.md`; no HTML5 UP demo photo was retained.
- No remote fonts, stock-image URLs, external image URLs, commercial icon packs, trackers, analytics, external form handlers, or other third-party runtime requests are included.
- Sample form submissions are prevented locally and explicitly say no information is sent.
