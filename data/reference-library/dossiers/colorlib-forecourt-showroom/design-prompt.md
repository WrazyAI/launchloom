# Reference implementation brief: Price-led automotive showroom

## Scope and non-copy rule

Use the paired local captures as evidence for the showroom's inventory-first information architecture, finance explainer, part-exchange workflow and branch presentation. The pinned template source is MIT licensed and its bundled photographs are individually documented as CC0 or Public Domain in the retained credits. Do not reuse the Forecourt name, dealership identity, vehicle descriptions, vehicle photos, finance figures, branch details, phone number, ratings, regulatory copy or claims. The demo content is illustrative. Populate every visible fact from sealed client and SEO tokens.

## Visual hierarchy

Create a bright, functional showroom interface rather than a generic dark automotive landing page. A restrained wordmark and compact utility controls sit in a shallow header. The first scene uses a wide, softly washed showroom photograph behind a clear price/value statement. Put a compact vehicle-finder directly beneath the promise so search feels like the primary product action, not an afterthought. Use a crisp grotesk, white and pale neutral surfaces, hairline borders, and a narrow orange action color. Keep inventory information dense but orderly: vehicle image first, then model, verified specification, and a clearly explained price or payment label.

## Page sequence

1. Wordmark, useful stock/finance/trade-in/branch navigation, and one real call or appointment action.
2. Showroom promise with a searchable/filterable vehicle finder.
3. Recent or selected inventory. Each item links to a real detail or enquiry path and uses client-approved vehicle images and data.
4. A payment explainer that describes the inputs and assumptions. Show an actual calculator only when the client supplies rates, terms and required disclosures; otherwise keep it as a plain explanation of finance options.
5. Part-exchange qualification with the minimum information needed to request a valuation.
6. Verified visit/branch information, practical FAQs, and a clear test-drive or stock-enquiry close.

Do not include fabricated inventory counts, finance APRs, monthly payments, vehicle history checks, valuations, guarantees, branch hours or reviews. If no live stock feed exists, label selections as examples only or use a request-to-confirm list. Never imply that a generic car image is a vehicle currently for sale.

## Responsive translation

At 390px, keep the wordmark, one contact route and the promise in the first reading sequence. Place the stock search directly under the opening copy; stack its fields rather than making the visitor pan sideways. Convert the three-column arrival grid into full-width inventory rows with image, model, verified details and action visible together. Keep finance assumptions next to any calculator, make part-exchange fields thumb-friendly, and stack branch information. Test at 390px and 320px with no horizontal page overflow and no sticky element covering the search or contact action.

## Signature elements

- Product-search opening with the finder directly attached to the hero promise.
- Inventory arranged as a price-and-specification comparison rather than a generic service-card wall.
- A separate, legible finance assumptions chapter.
- Part-exchange as a focused valuation request rather than a long contact form.
- Branch/visit information presented as utility data with an accurate route to each verified location.

Use vehicle photography only when the client has permission to show those exact cars. Keep pricing, finance, branch, and product-detail elements visually distinct; do not invent interactive controls that have no real data behind them.

## Prohibited patterns

- Copying Forecourt branding, source copy, source photographs, vehicle names or screen layout pixel-for-pixel.
- Inventing inventory totals, APR, payment examples, fees, valuations, warranties, inspection status or regulatory claims.
- Presenting a stock photo as a vehicle currently available or as the client's actual premises.
- Showing a live price calculator without validated rates, terms, and disclosures.
- Adding generic review cards, a glass-pill navigation bar, decorative counters or a large unrelated bento grid.
- Treating all dealerships, workshops and rental businesses as the same business category.

## Local SEO and conversion

Use the verified dealership type, actual location, vehicle categories and inventory terms customers use in the local market. Clarify whether the business sells new vehicles, used vehicles, or both only from intake facts. Keep dealership location data consistent with LocalBusiness structured data and distinguish each real branch from areas merely served. Use the primary action to search actual stock, request a test drive, or ask about a vehicle, whichever the business can fulfill. Finance language must remain accurate, compliant and explanatory; no SEO phrase justifies a made-up price or finance claim.
