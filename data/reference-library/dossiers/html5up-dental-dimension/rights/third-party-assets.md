# Included asset and dependency audit

- The only retained upstream implementation assets are `render/assets/css/main.css` and `render/assets/css/noscript.css`, based on the pinned Dimension source and covered by the retained CC BY 3.0 license record.
- The original upstream CSS header attribution is preserved. The Google Fonts and Font Awesome imports were removed. The upstream image assets, font binaries, jQuery/plugins, and script bundles were not copied.
- `render/assets/css/adaptation.css` and `render/assets/js/prototype.js` were written for this fictional study. They use native CSS and browser APIs only.
- Photos in `render/images/` are original generated assets described in `generated-assets.md`.
- No remote fonts, stock-image URLs, external image URLs, commercial icon packs, trackers, analytics, form services, or other third-party runtime requests are included.
- The contact form is a local-only preview interaction. It prevents network submission and explicitly says no information is sent.
