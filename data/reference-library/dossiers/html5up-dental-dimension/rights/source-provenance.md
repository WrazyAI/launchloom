## What is retained and changed

The layout and interaction vocabulary is adapted from Dimension: one centered identity stage, a partitioned section index, and one focused overlay panel at a time. The provided CSS base was modified; text, semantic structure, colors, nav labels, imagery, metadata, and interaction code were replaced or rewritten for this fictional dental concept. The original demo photography, original Font Awesome files, Google Fonts import, and upstream JavaScript/vendor libraries were not copied. All displayed photography is project-generated and listed with prompts and hashes in `generated-assets.md`.

The desktop/mobile captures are of this clearly modified local adaptation, not screenshots of the HTML5 UP live demo. The screenshot adaptations are stored under the same CC BY 3.0 attribution context as the modified template. This study is not endorsed by HTML5 UP or AJ and must not be used to imply such endorsement.

Visible attribution appears in the study footer and the source headers remain in the copied CSS. Changes are identified in this file and in the design prompt. Downstream adaptations must preserve this attribution where the licensed source is distributed or publicly performed.
