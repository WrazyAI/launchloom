# Reference implementation brief: Research rail and hospitality project archive

## Scope and non-copy rule

Use the paired captures to study an architectural/interior practice presented through a dramatic wordmark, a contrasting research rail, warm mineral surfaces, annotated project records and a dark close. The original practice specializes in hospitality and interiors; adapt the information architecture only. Do not reproduce Groth's logo, orange panel, project photos, project names, drawings, location list, staff or text. Do not copy any restaurant interiors or source artwork into a client's live page. Use client-provided imagery and verified SEO/business facts only.

## Visual hierarchy

Start with a typographic masthead large enough to function as the first visual object, paired with a small label describing the actual practice. Place a narrow contrasting annotation rail at desktop's right edge for material research, diagrams or a useful studio note. The main portfolio sits on a muted cream/stone surface. Treat every project as a compact evidence record: one clear title, a concise factual description, one line drawing or process image, one finished image where approved, and a link. A mix of line illustration and photography gives the project list its cadence. Close with a deep olive/charcoal panel for contact and utility links.

## Page sequence

1. Micro-utility strip and navigation for Projects, Services, About, FAQs and Contact.
2. Oversized wordmark/masthead beside a compact, factual practice description.
3. Desktop research/material rail that annotates the project narrative without becoming a second competing page.
4. Project archive with alternating drawing, photograph, description and link, each showing only confirmed project data.
5. Short studio/process section explaining how an enquiry proceeds.
6. Factual hospitality/interior service list and relevant FAQs, informed by client facts and keyword research.
7. Dark contact close with a clear project consultation action and verified business details.

## Responsive translation

At 390px, remove the two-column research rail as a fixed sidebar. Recompose each note inline between project records, preserving the drawing/photo pairing as stacked images with captions. Scale the wordmark fluidly and keep the navigation compact. Project summaries must remain long enough to explain type and service context without forcing a horizontal rail. Show services and FAQs in the page, and move the dark contact close after the last project/process chapter. Check 390px and 320px for type clipping and horizontal overflow.

## Signature elements

- Oversized brand masthead with a small practice descriptor.
- Narrow contrasting research/annotation rail on desktop, translated into editorial interludes on mobile.
- Alternation between line drawings and finished project photography.
- Compact, factual project records instead of generic rounded work cards.
- Dark, quiet contact footer.

## Prohibited patterns

- Copying Groth's wordmark, typography, orange rail, projects, clients, imagery, drawings, or written material.
- Presenting project photography or architecture as the new client's work without approval.
- Faking project dimensions, client brands, sustainability results, materials, awards, or completion dates.
- Turning the research rail into a fake status dashboard or metrics panel.
- Letting the wordmark replace the required service, geographic, FAQ and contact information.
- A sticky desktop rail that overlaps content or persists on mobile.

## Local SEO and conversion

Use a locally relevant service statement in visible copy and metadata that identifies the actual hospitality/interior/architecture scope and verified service area. Project pages should link to substantive approved case studies rather than thin locality variants. Use area-served language accurately; do not infer an office. The first contact route should be a project discussion or consultation appropriate to client operations. Include questions around project fit, services, process and geographic coverage, with answers from verified data. Never sacrifice truthful SEO details for art direction.
