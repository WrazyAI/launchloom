## Capture method and limits

The desktop and mobile PNGs were captured from a local render of the downloaded
HTML package, not from the gallery, its preview screenshot, or a LaunchLoom
study. Source layout, art and text were not changed before capture. This static
HTML distribution keeps click-driven controls in their initial visual state;
its own README says interactive behavior is presentational in this build.
Product mechanics in the design prompt are grounded in Spicer Designs'
template description and are not claimed as tested in this static capture.

The demo includes fictional sample pricing, locations, estimates, reviews,
service coverage and guarantees. These are evidence of the source layout only.
They must not be reused as client facts, SEO content, testimonials, offers or
performance claims.
