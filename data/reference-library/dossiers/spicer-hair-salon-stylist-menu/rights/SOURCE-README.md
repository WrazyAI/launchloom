# Free Hair Salon Website Template — plain HTML



No build step, no Node, no install. Open `index.html` in a browser and it
works. Upload the folder to any host and it is live.

## What is in here

    index.html    the whole page
    styles.css    compiled Tailwind — only the classes this page actually uses
    hero.webp     the hero image

Everything is in `index.html`. Edit the text directly, and edit `styles.css`
if you want to change the type or add rules. The animations are declared in a
`<style>` block inside `index.html` itself, so they travel with the page.

## What this version does not do

This is rendered from the same source as the React version of this template,
which means the layout, the content and the styling are identical. What does not
carry over is JavaScript behaviour:

- Anything driven by a click — a slot picker, a stepper, a before/after slider —
  is presentational here. It renders in its starting state and does not respond.
- The FAQ accordions **do** work; they are native `<details>` elements and need
  no JavaScript at all.
- The contact forms do not submit anywhere. They do not in the React version
  either — you have to point them at your own handler.

If you want the interactive versions, download the React build of this template
from https://www.spicerdesigns.com instead.

## The hero image

`hero.webp` is **AI-generated placeholder artwork**, not a photograph of any
real premises, and it is deliberately atmospheric rather than a picture of staff
or customers — no faces, no signage, nothing that could be mistaken for a real
business. Swap it for your own photography before launch.
